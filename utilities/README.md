# Utilities

A Stream Deck plugin with small, handy keys.

## Simple Clock

A plain-text key showing the time.

- Any time zone, or *Local time*. Daylight saving is handled automatically.
- 24-hour or 12-hour (am/pm), as `HH:mm` or `HH:mm:ss`.
- An optional **Prefix** shown above the time, such as a city name.
- Font, size, style and colour come from the **T** menu next to Stream Deck's Title box. Leave that box empty: a
  title typed there replaces the clock.
