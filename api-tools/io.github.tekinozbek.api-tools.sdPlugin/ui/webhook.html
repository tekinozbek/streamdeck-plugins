Expressions

Used by Expression, Icon and URL to open. They read values from the JSON the API returns.

data.items[0].countplain path
{cpu.name}: {cpu.temp}join values
={a} + {b}maths: + - * / % and ( ). After =, functions go outside the braces: =round({a}, 2)
{time.hour}:{pad({time.minute}, 2)}functions inside {}
{name}[0:5] {name}[:-1] {name}[-1]Python-style slice / index
={t}[0:2] * 60numeric text converts automatically
Functions
round(x, digits) fixed(x, digits) floor(x) ceil(x) abs(x) min(…) max(…) pad(x, width, char)

fixed(x, 1) always shows the decimals (5 → 5.0). Halves round away from zero.

Rules
  • Text with no {} and no leading = is read as a path. Use {…} for literal text.
  • + adds numeric-looking text ("1"+"2" = 3). Join with {a}{b} instead.
Display
  • The key shows Prefix + the Expression result + Suffix.
  • \n = new line, in Expression, Prefix and Suffix (e.g. {name}\n{temp}°C).
Icon

An expression that returns an image from the response JSON:

  • SVG markup, or a data:image/svg+xml URI (max 256 KB). Scripts and animation are refused, as are <use> references that loop or multiply without limit.
  • PNG (also JPEG, GIF, WebP) as a data:image/png;base64,… URI or bare base64 (max 512 KB).
  • Empty or missing value: the default icon is restored.
  • Unusable image: a red BAD ICON tile is shown.
  • SVG: scripts, foreignObject, event handlers and external links are blocked. Give it a viewBox so it scales.
Open URL on press

With Behavior → Open URL in browser, pressing the key opens the URL in your default browser. Only http and https are allowed.

https://example.com/?tz={tz}value from the API response, URL-encoded
{!url}inserted as-is (e.g. the API returns a full URL)
https://e.com/{pad({n}, 3)}functions and slices work too

While polling, the latest response is used. Otherwise the API is called first, using the Request settings. A missing value anywhere in the URL (even inside a function) cancels the open. A URL with no {} opens immediately.

Timeout and redirects
  • Timeout (s): 1 to 120 seconds. Empty or 0 = 10 s; above 120 counts as 120.
  • Redirects are never followed, so your headers, body and query string can't be sent anywhere else. If the API answers with a redirect the key shows REDIRECT; use the final URL instead.
Polling
  • Every (ms): 0 = off. Minimum 250. GET and HEAD only.
  • A request waits at most max(3 s, 3× the interval) before the next try, even if Timeout is longer.
Errors on the key
HTTP 404the API answered with that status
TIMEOUT / NO CONNno answer in time / could not connect
REDIRECTthe API answered with a redirect (not followed)
BAD JSONresponse is not JSON (needed by the expression, icon or URL)
TOO BIGresponse over 1 MiB
ERRthe expression failed

With an Icon set, the error is drawn as a red tile that replaces the icon. Otherwise it is shown as the title. It clears on the next successful call.

Privacy

URL, headers and body are saved as plain text in your Stream Deck profile and are included if you export or share it. Remove tokens first.
